# Claude Code Guide

Start here when working on this repository with Claude Code:

- `docs/KNOWLEDGE_BASE.md`

That file is the canonical knowledge base for both Claude Code and Codex. It documents:
- the app's purpose and runtime model
- key source files
- Claude account switching flow
- Claude and Codex usage tracking details
- updater and release behavior
- persisted state and settings
- UI conventions and known risks

Keep `docs/KNOWLEDGE_BASE.md` current whenever you make meaningful product, architecture, or workflow changes.
