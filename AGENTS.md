# Agent Guide

This repository keeps its canonical agent knowledge base in:

- `docs/KNOWLEDGE_BASE.md`

If you are an agent working in this project, read that document first before making changes.

It contains:
- architecture and file ownership
- Claude and Codex usage integration details
- updater behavior
- launch-at-login behavior
- persistence and settings notes
- UI conventions and known maintenance risks

When in doubt, treat `docs/KNOWLEDGE_BASE.md` as the source of truth and update it alongside significant product or architectural changes.
